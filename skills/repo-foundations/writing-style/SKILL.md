# Writing style

Scope: prose artifacts (AGENTS.md, docs/, README, skill files). Commit
messages and code comments follow each repo's conventions, not this skill.

## Rules (absolute)

- English only. Chat may be another language, artifacts never.
- No em dashes. No semicolons.
- Short paragraphs, short bullets. Every sentence adds information: cut
  the sentence that only rephrases the previous one.
- Evergreen: durable rationale, never session play-by-play ("today we",
  "as discussed", "recently").

## Voice

Direct and technical: declarative sentences, no greetings, no preamble, no
hedging. State the rule, then the reason, then stop.

## Audience before writing

- **AGENTS.md** — rules an agent must follow every session.
- **README** — humans first: what is this, how do I use it, how do I work
  on it.
- **docs/** — on-demand depth for either audience; one policy per doc.

Say who the artifact is for before writing it, and cut everything that
audience does not need.
